## 2. Changements réalisés

### Tokens & meta
- [`index.html`](../index.html) : `lang="fr"`, `theme-color="#2B4B8C"`
- [`src/index.css`](../src/index.css) : variables `--yh-brand`, `--yh-bg`, `--yh-ink`, `--yh-scrim` + classes `.yh-scrim` / `.yh-toast`
- Login / accès refusé / spinner : fond stone `#F5F5F4`, CTA navy brand

### Shell navigation ([`src/App.tsx`](../src/App.tsx))
- Groupes **Ops / Finance / Admin**
- Couleur active unique `#2B4B8C`
- Scrim mobile (tap dehors → ferme le drawer)
- Titre sidebar « Édition reçu » en mode formulaire

### Formulaire reçu
- Accordion : Client / Séjour / Versements ouverts ; Tarification, Options, Hôtes, Notes repliés (auto-ouverts si données présentes)
- Barre sticky mobile : Aperçu + Sauver + toggle moyens de paiement

### Calendrier ([`src/components/CalendarView.tsx`](../src/components/CalendarView.tsx))
- **&lt; md** : bandeau semaine (compteurs d’occupation) + **mini-grille 7 jours × logements** (même lecture rapide qu’au PC) + détail du jour (filtre Actifs / Tous)
- **≥ md** : grille mensuelle inchangée
- Header mobile : toggles Résa / Ménage / Présence empilés

### Historique + feedback
- Boutons commission / caution remontés à `text-[10px]` + zones tactiles plus grandes
- Succès → toast non bloquant (~3,2 s) ; erreurs / infos → modal

## 5. Déploiement prod

La prod **frontend** est **GitHub Pages** (workflow [`.github/workflows/deploy.yml`](../.github/workflows/deploy.yml) sur push `main`).  
`firebase.json` n’expose pas de hosting — Firebase reste Auth / Firestore / Functions / Storage.

**Ne pas déployer** tant que l’utilisateur n’a pas donné son OK explicite.  
Ensuite : merge / push sur `main` (ou `workflow_dispatch` sur l’Action).
